# Pi Magpie

Pi Magpie shows readings from Magpie in a Pi session.

## Language

**Card**:
A Magpie quota report entry for one provider subscription, plan, or key balance. A provider can have more than one Card.

**Window**:
One allowance within a Card. A Window can have a remaining percentage, a balance, or text instead of a percentage.

**Reading time**:
The time Magpie read a Card. A missing or old Reading time makes the Card stale.

# Deterministic conditions resolve themselves

`/pr` routes as an explicit priority ladder and resolves every condition that needs no human judgment before it stops. Local state is normalized first: a local HEAD behind the PR head is fast-forwarded, and clean local commits that diverged from it are rebased onto it; neither step pushes, stashes, or resets, and a conflicting rebase is aborted back to the original HEAD. Mergeability that GitHub has not finished computing (`UNKNOWN`) is a transient condition, so `/pr` re-reads a bounded number of times instead of reporting a policy block. GitHub reports `BEHIND` only when repository policy requires an up-to-date branch, so it is a merge blocker that never clears on its own; `/pr` now runs the same pinned-base rebase and exact-lease push it already used for confirmed conflicts. Stopping in these states only postponed an outcome the machine could already prove safe.

This supersedes the "base BEHIND does not trigger a rebase" clause in ADR 0002 and the "behind requires a base update, no action" boundary in ADR 0001. Uncommitted work on a diverged branch is not a stop either: local publication commits the owned paths under its existing ownership review, the committed branch is synced onto the PR head, and a second publication pass validates and pushes it. Semantic conflicts, ambiguous ownership, local merge commits, unfixable checks, human review, running CI, budgets, and uncertain mutations still stop. Running CI with no other blocker is also deterministic: the invocation waits, polling GitHub every `ciPollSeconds` (default 30) for at most `ciWaitMinutes` (default 10) per invocation, then routes the fresh state. The wait happens only inside an explicit, user-started `/pr`; passive presentation still never polls, and GitHub auto-merge is never enabled because the post-wait re-read must still triage comments that arrived during the run. The direct merge uses a configured `mergeMethod` (squash by default) instead of a fixed squash, so repositories that disallow squash can still finish through `/pr`; GitHub remains the authority on which methods a repository permits.

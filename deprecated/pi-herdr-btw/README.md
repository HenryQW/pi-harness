# `@henryqw/pi-herdr-btw` (retired)

Merged into [`@henryqw/pi-herdr-tools`](../../extensions/pi-herdr-tools/README.md). Published versions are no longer maintained.

The final pre-merge source, documentation, and tests are preserved here for reference. This archive is not an active workspace; use the replacement rather than loading its old entry point.

Install the replacement, then remove this package to avoid duplicate command registration:

```sh
pi install npm:@henryqw/pi-herdr-tools
pi remove npm:@henryqw/pi-herdr-btw
```

For project-local installs, use `--local` on both commands. Remove manually configured old entry-point paths and restart Pi. Commands, BTW configuration and pending deliveries, title session entries, and task-model assignments retain their existing formats and IDs; no data migration is needed. See the replacement README for the complete migration.

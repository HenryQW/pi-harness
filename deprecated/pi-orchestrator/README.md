# `@henryqw/pi-orchestrator` (retired)

Retired. `@henryqw/pi-subagent` is also retired. Direct delegation uses `npm:billion-context` and `acp_delegate`. Checked worktrees have no replacement.

Remove existing installs with `pi remove npm:@henryqw/pi-orchestrator`. See [`deprecated/pi-subagent/README.md`](../pi-subagent/README.md).

Existing `~/.pi/agent/config/pi-orchestrator/` state is not migrated. Published versions are no longer maintained.

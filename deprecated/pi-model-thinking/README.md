# `@henryqw/pi-model-thinking` (retired)

Retired because Pi v0.84.3 added native per-model thinking defaults. Keeping this extension would create a second, conflicting source of configuration.

Remove existing installs with `pi remove npm:@henryqw/pi-model-thinking`, then use `/settings` → **Default thinking level per model**. Numbered Codex account aliases must be configured separately in Pi's native settings.

Existing `~/.pi/agent/config/pi-model-thinking.json` values are not migrated. Published versions are no longer maintained.

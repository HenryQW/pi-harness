# `@henryqw/pi-prompt-creator` (retired)

Retired because it gave too little value. There is no replacement. Published versions are no longer maintained.

The final source, documentation, and tests are preserved here for reference. This archive is not an active workspace; do not load its old entry point.

Remove the package, then restart Pi:

```sh
pi remove npm:@henryqw/pi-prompt-creator
```

For project-local installs, use `--local`. Prompts saved with `/promptor save` stay in `~/.pi/agent/prompts/` and continue to work as usual Pi prompt templates. Existing `~/.pi/agent/config/pi-prompt-creator/` config is not used and you can delete it.
